Changelog of zmk-nice-oled.
https://github.com/mctechnology17/zmk-nice-oled/blob/main/CHANGELOG.txt

How the versions work (the third number is the ZMK version):
- v0.0.3.N        versions for ZMK v0.3 (branch `zmk-v0.3`, and `main` while it is on ZMK v0.3)
- v0.0.4.N        versions for the next ZMK version (v0.4)
- vX.Y.Z-beta.N   public test version from the branch `beta`
- New work is developed on the branch `dev`

# FEATURES v0.0.4 (not released yet, branch `zmk-v0.4`) · next ZMK (Zephyr 4.1)
=======================================
Migration to the next ZMK version. This branch does not build with ZMK v0.3: use `main` or `zmk-v0.3` for that.

# CHANGES
- [x] **LVGL 9** canvas drawing goes through layers (`canvas_draw_*` in `widgets/util.c`), the canvas uses the L8 color format and the images use `LV_COLOR_FORMAT_I1`
- [x] **Output widget** shows the disconnected icon when no output is connected (`ZMK_TRANSPORT_NONE`)
- [x] Renamed ZMK functions (`zmk_endpoint_get_selected`, layer functions with the new argument) and removed Kconfig options (`LV_USE_IMG` is now `LV_USE_IMAGE`)
- [x] **Display thread stack** 8192 bytes, set in the shield `.conf` files: LVGL 9 uses 3784 bytes and the 3072 of ZMK overflowed at boot
- [x] **LVGL memory pool** doubled: central 16384, peripheral 8192
- [ ] Tested on a Corne with vikoto and nice!view only; the look of every widget still has to be checked on OLED

# NEW FEATURES
- [x] **Street theme** CONFIG_NICE_OLED_WIDGET_STREET: a character instead of the WPM widgets. It stands, walks, runs and sprints with the typing speed, jumps with GUI, punches with Ctrl, kicks with Alt, throws an uppercut with Shift and takes a bat out with Caps Lock. 68x90 on a nice!view, 32x24 on an OLED
- [x] **Behavior &street** (`#include <behaviors/street.dtsi>`): any animation of the character on any key, layer or macro, and switches for the bat (for caps word, which does not light the Caps Lock indicator)
- [x] **Car chase** on the peripheral half: CONFIG_NICE_OLED_WIDGET_ANIMATION_PERIPHERAL_STREET_CHASE
- [x] **Sleep art** of the theme: CONFIG_NICE_OLED_SLEEP_ART_STREET
- [x] **Bluetooth profiles as stars**: CONFIG_NICE_OLED_WIDGET_STREET_STARS
- [x] **tools/street_assets.py** draws every image of the theme
- [x] **README** two GIFs of the street theme: every animation of the character (`assets/street_demo.gif`) and the theme on a Corne with two nice!view (`assets/street_keyboard.gif`)
- [ ] Street theme: the small character and the sleep art for OLED are not tested on a display; the bat animation still needs its own four poses

# FEATURES v0.0.3 (Jan 09, 2026)
=======================================
Tagged as v0.0.3 on Nov 18, 2026 (last commit of Jan 26, 2026). Tested with ZMK v0.3.

# NEW FEATURES
- [x] **Bongo Cat for Modifiers Indicators** CONFIG_NICE_OLED_WIDGET_MODIFIERS_INDICATORS_BONGO_CAT added
- [x] **New macro** MODIFIERS_USE_BONGO_CAT for conditional compilation
- [x] **New Variable** CONFIG_ZMK_DISPLAY_BLANK_ON_IDLE Now the user decides whether to activate this function for @nice_custom and @nice_epaper
- [x] **Battery performance and Better resource management for the peripheral side** CONFIG_LV_Z_MEM_POOL_SIZE=4096 CONFIG_ZMK_DISPLAY_DEDICATED_THREAD_STACK_SIZE=2560
- [x] **Sponsor Links** added github, paypal, buymeacoffee and revolut
- [x] **CODE_OF_CONDUCT.md** added

# FIXES
- [x] COMMIT: fix: HID Indicators and Modifiers animation can now be fully disabled, feat: Bongo Cat for Modifiers
- [x] **HID Indicators animation fix** Luna animation no longer appears as fallback when user disables both Luna and BongoCat
- [x] **Modifiers Indicators animation fix** Luna animation now respects CONFIG_NICE_OLED_WIDGET_MODIFIERS_INDICATORS_LUNA flag
- [x] **New macros** HID_HAS_ANIMATION, MODIFIERS_USE_SYMBOLS, MODIFIERS_USE_LUNA, MODIFIERS_USE_BONGO_CAT, MODIFIERS_USE_NONE for conditional compilation
- [x] **Changed default** CONFIG_NICE_OLED_WIDGET_HID_INDICATORS_BONGO_CAT from y to n (no animation by default)
- [x] **replaced a reference** to CONFIG_NICE_OLED_GEM_ANIMATION_MS, which does not exist, with CONFIG_NICE_OLED_WIDGET_ANIMATION_PERIPHERAL_MS, which i believe is the (now generic) replacement, thanks @newx-it
- [x] **HID Indicators position** set with CONFIG_NICE_OLED_WIDGET_HID_INDICATORS_CUSTOM_X and CONFIG_NICE_OLED_WIDGET_HID_INDICATORS_CUSTOM_Y; default values of new and existing variables documented in README.md (Jan 11, 2026)
- [x] **Kconfig.defconfig** small fix for CONFIG_NICE_OLED_WIDGET_HID_INDICATORS_BONGO_CAT (Jan 11, 2026)
- [x] **Static image on the peripheral** missing vim symbol added, thanks @Mrxyx (Jan 26, 2026)

# BREAKING CHANGES
- [x] HID Indicators no longer shows any animation by default. Users who want Luna or BongoCat must explicitly enable them in their .conf file
- [x] Modifiers Indicators now requires explicit CONFIG_NICE_OLED_WIDGET_MODIFIERS_INDICATORS_LUNA=y or CONFIG_NICE_OLED_WIDGET_MODIFIERS_INDICATORS_BONGO_CAT=y to show animation
